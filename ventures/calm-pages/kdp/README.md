## Description
One gentle page a day, about five minutes.

Calm Wings is a 90-day journal for anyone who worries. Each day you check in with your mood, write three
good things, name one worry and a more balanced thought, and pick one small step for tomorrow.

Inside:
- 90 undated daily pages, so you can start any day and skip days without guilt
- An SOS toolkit for hard moments: box breathing, 5-4-3-2-1 grounding and a worry tree
- Weekly "I handled it" check-ins and monthly habit trackers
- A butterfly coloring page at the end of each week
- Short, plain-language pages on how anxiety works

Calm Wings is for self-reflection and general wellbeing. It supports, not replaces, care from a licensed
professional. If you are in crisis in the US, call or text 988.
