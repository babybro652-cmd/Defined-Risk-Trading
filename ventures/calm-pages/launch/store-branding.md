# Peace by Page: Payhip store branding (launch step 22)

## Images (in `ventures/calm-pages/brand/`)

| File | Size | Use it for |
|---|---|---|
| `payhip-logo.png` | 1000 x 1000 | Store logo / profile image (same style as the Facebook profile) |
| `payhip-favicon.png` | 512 x 512, transparent | Favicon (browser tab icon): Store builder > Change store style > Favicon. Payhip shows it only once a custom domain (peacebypage.com) is connected. |
| `payhip-banner.png` | 2400 x 800 (3:1) | Store banner / hero image. Start with this one. |
| `payhip-banner-slim.png` | 2400 x 600 (4:1) | Use if the theme crops the 3:1 banner (title or labels cut off) |

Payhip doesn't publish a fixed banner size. Its help center says to try aspect ratios in the Store Builder, so both versions keep everything important in the middle. Check the store on a phone after uploading; if the edition names get cut off, switch to the slim one.

## Store About text

```
Hi, and welcome to Peace by Page.

We make gentle printable journals for anyone who worries. Each one asks for about five minutes a day: a few ratings, three good things, one worry and a kinder way to look at it, and one small step for tomorrow. Pages are undated, so you can start any day and skip days without guilt.

The prompts draw on well-known self-help ideas like CBT-style thought records, worry time, grounding and gratitude writing, with coloring pages as a small reward for showing up. Every journal comes in three editions with the same pages: Calm Wings (butterflies), Calm Petals (botanical) and Calm Nights (moon and stars, for evenings). Every file comes in US Letter and A4, ready to print at home.

Not sure yet? Start with the free 7-day sampler.

Please note: our journals are self-reflection tools for general wellbeing. They are not medical advice, diagnosis or treatment, and they support, not replace, care from a licensed professional.

If you need help now: in the US, call or text 988 (Suicide and Crisis Lifeline), any time. In an emergency, call 911. Outside the US, call your local emergency number or visit findahelpline.com.
```
