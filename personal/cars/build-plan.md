# Car build plan: phases and costs

Goal: high-performance street cars with aggressive styling. Order on every car:
**1. Reliable and safe → 2. Power → 3. Looks.** Plan written 10/12/2026.

**Updated 10/23: build once (Charger and Cruze).** Tim wants reliability and no building now
and redoing later. Order on those two: chassis items first (brakes, suspension, body, interior,
wheels) whenever money allows, then the engine and every part tied to power (fuel, cooling,
tune, transmission, axles, driveshaft) all at once, sized for the final power from day one.
One tune, one install. A fresh engine at moderate boost beats boosting a high-mile engine.
Charger: forged 392, Whipple 3.0L twin-screw at about 7 psi (about 650-700 crank hp), 8HP90, all
in the plan. Traditional supercharger, no ProCharger (Tim, later 10/23).
Cruze: engine is apart, so it is built once now (full valve job, forged-piston refresh, every
weak point, new turbo). Details: [build-guides.md](build-guides.md). All four:
$97,290–212,450 became $111,440–237,730, then $112,540–237,530 with the Whipple.

**Parts lists (10/21):** brand-level parts for every build are in [parts-lists.md](parts-lists.md).
The parts lists raised some lines; each changed line shows its old range as "was". Net change:
Cruze +$2,700 to +$4,600, Charger +$3,500 to +$5,500, Cutlass +$5,100 to +$5,600, Hayabusa
+$150 to +$600. All four: $77,490–183,300 became $88,940–199,600.
Tim's build decisions later on 10/21 (Cutlass console shifter, Ridetech coilover system, 7x6 LED
headlights, RestoMod Air; Cruze gloss black wrap and burnt orange interior) moved it to
$95,590–210,150. Remote start, alarm and keyless systems for the Cutlass and Charger (10/21) moved it to $97,290–212,450.

Costs are rough parts-only ranges (2026 prices) assuming Tim does the labor. Shop labor,
paint and surprises (rust, a bad bottom end) add on top. Get real quotes before buying.
This is a list for later, paid from extra money, never from bill money.

## Order across the four vehicles

1. **Charger oil change now** (past due). It's the running car.
2. **Cruze head back on** and the car running again.
3. Charger and Cruze brakes, oiling and chassis (10/23: Cruze engine is built once in step 2).
4. Charger power package, all at once, once it is paid for (10/23).
5. Cutlass, the biggest build, once the other two are done or as cash allows.
6. Hayabusa (added 10/21): find and fix the oil drips and service it now; build phases as cash allows.

### Charger AWD option (reference only, not the plan)

Two ways to do it. Prices are rough; Path B is one-off custom work, so get a quote from a shop that has done LX drivetrain swaps.

**Path A: factory AWD parts from a donor (2011+ AWD Charger or 300 with the 5.7).** Fits a mild blower only (about 550 hp, gentle launches). Nothing stronger bolts in.

| Work | Cost |
|---|---|
| AWD front crossmember, control arms, knuckles and hubs, front diff, front axles | in donor price |
| AWD 8HP70 with the active transfer case, front and rear driveshafts | in donor price |
| AWD oil pan and pickup, engine mounts, steering rack if different | in donor price |
| Donor car or parts set (used) | $3,000–6,000 |
| Program the engine, transmission, ABS and body computers for AWD | $300–800 |
| **Path A total** | **about $3,300–6,800**, plus 2–4 weekends of your labor |

Weak points: the transfer case and front diff. The front and rear diff ratios must match, which limits gear changes.

**Path B: built AWD for 650+ hp.** Uses the stronger Trackhawk / Durango Hellcat drivetrain (built for 707+ hp). It does not bolt into a Charger, so most of this is fabrication.

| Work | Custom work needed | Cost |
|---|---|---|
| 8HP95 transmission with the Trackhawk transfer case (used) | New transmission crossmember; check tunnel clearance | $4,000–7,000 |
| Transmission crossmember and tunnel work | Fabricate mounts, trim or massage the tunnel | $1,500–3,000 |
| Wiring and computer integration | Make the Trackhawk transmission and transfer case modules talk to the Charger; custom tune | $1,000–2,500 |
| Trackhawk front diff (used) | Fabricate front diff mounts in the Charger crossmember | $800–1,500 |
| Front diff mounts | Fabrication | $1,000–2,000 |
| Custom front axles | Built to fit the Trackhawk diff and Charger AWD knuckles | $1,500–3,000 |
| Custom front driveshaft, one-piece rear driveshaft | Measured after the swap | $1,500–3,000 |
| Match front and rear gear ratios | Regear the rear to match the Trackhawk front ratio | $800–2,000 |
| Oil pan clearance with the supercharger | AWD pan, check blower and front diff clearance | $300–600 |
| Transmission and transfer case coolers | Plumbing | $300–600 |
| Shop labor for fabrication and install | | $5,000–12,000 |
| **Path B total** | | **about $17,700–37,200** on top of the rest of the build |

Bottom line: Path A caps the power; Path B costs about as much as the supercharger, wide body and paint combined. RWD with the parts above holds more power for far less.
